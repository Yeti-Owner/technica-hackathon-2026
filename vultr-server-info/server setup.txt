VULTR SERVER SETUP: AI IMAGE CHECK

SERVER

APP (on server, /root/ai-check/)
- app.py        Flask server, listens on port 80
- config.json   api_key (OUR key, sent as X-API-Key header) + SightEngine api_user/api_secret  <-- NEVER COMMIT THIS FILE'S CONTENTS
- cache.db      SQLite cache: sha256 -> score, source, timestamp
- venv/         Python venv (flask, pillow, requests)
- Service: systemd unit "ai-check.service" — enabled, auto-starts on boot, restarts on crash
- Firewall: ufw ACTIVE — allows only 22/tcp (SSH) and 80/tcp (HTTP)

API
- GET  http://SERVER_IP/health   ->  {"ok": true}
- POST http://SERVER_IP/check    (requires header: X-API-Key: <api_key from config.json>)
  - by URL:   -d "url=https://example.com/image.jpg"
  - by file:  -F "file=@C:\path\to\image.jpg"
  - response: {"id": "<sha256 of image bytes>", "score": 0-100, "source": "...", "cached": true/false}
  - source values: local | sightengine | cache | inconclusive
  - score 50 + source "inconclusive" = no information; valid requests NEVER error
- Windows note: in PowerShell use curl.exe (plain `curl` is Invoke-WebRequest and breaks on -H)

PIPELINE (what /check does, in order)
1. Check X-API-Key
2. Get image bytes (download the URL itself, or read the uploaded file; 15MB cap)
3. sha256 the bytes -> cache lookup (hit = instant response, cached: true)
4. Local metadata tests (no ML, never decodes pixels):
   - PNG text chunks (parameters / prompt / Software: Stable Diffusion / NovelAI / ComfyUI tags) -> 95
   - JPEG EXIF Software or ImageDescription containing AI tool names -> 95
   - EXIF camera Make + Model present (real photo) -> 10
5. Inconclusive -> SightEngine models=genai, probability x 100
6. SightEngine down/out of quota -> score 50, source "inconclusive"

SIGHTENGINE FACTS
- Free tier: 2,000 operations/month. genai model costs 5 ops per call -> ~400 images/month
- Credentials live only in /root/ai-check/config.json on the server

- Live logs:       journalctl -u ai-check -f
- Edit config:     nano /root/ai-check/config.json   (then restart the service)
